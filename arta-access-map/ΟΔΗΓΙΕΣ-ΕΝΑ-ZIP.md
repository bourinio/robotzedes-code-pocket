# Προσβάσιμη Άρτα – ανέβασμα με ΕΝΑ zip (χωρίς ρυθμίσεις)

Αρχείο: **arta-static.zip** (φτιάχνεται με `npm run build:local`).

## Ανέβασμα στο Cloudflare
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Upload assets**.
2. Όνομα, π.χ. `prosvasimi-arta` → σύρε μέσα το **arta-static.zip** → **Deploy**.

Αυτό είναι όλο. Η εφαρμογή είναι στο `https://prosvasimi-arta.pages.dev`.
Για νέα έκδοση: **Create deployment** και ανέβασμα του νέου zip.

## Εγκατάσταση στο κινητό (με το εικονίδιο)
- **Android (Chrome):** άνοιξε τη διεύθυνση → μενού ⋮ → **«Εγκατάσταση εφαρμογής»** (ή «Προσθήκη στην αρχική οθόνη»).
- **iPhone (Safari):** άνοιξε τη διεύθυνση → **Κοινοποίηση** → **«Προσθήκη στην οθόνη Αφετηρίας»**.

## Τι να ξέρεις
- Όλοι βλέπουν τα **37 γνωστά προσβάσιμα σημεία** της Άρτας.
- Ό,τι προσθέτει κάποιος (σημεία, φωτογραφίες, λογαριασμός) **μένει στο δικό του κινητό**: οι άλλοι δεν το βλέπουν.
  Ο πρώτος λογαριασμός σε κάθε κινητό είναι ο «διαχειριστής» εκείνου του κινητού.
- Για κοινά δεδομένα και έγκριση υποβολών από έναν διαχειριστή χρειάζεται η πλήρης έκδοση
  (`arta-cloudflare.zip`, οδηγίες στο ΟΔΗΓΙΕΣ-CLOUDFLARE.md).
- Μετά το πρώτο άνοιγμα δουλεύει και χωρίς ίντερνετ (εκτός από τους δρόμους του χάρτη).
