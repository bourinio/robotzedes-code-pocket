# Προσβάσιμη Άρτα – Διαδραστικός χάρτης προσβασιμότητας

Web εφαρμογή με χάρτη της Άρτας που δείχνει τα προσβάσιμα σημεία της πόλης (ράμπες, WC ΑμεΑ,
θέσεις στάθμευσης, δημόσιες υπηρεσίες, καταστήματα κ.ά.). Οι χρήστες κάνουν λογαριασμό και
προτείνουν νέα σημεία ή φωτογραφίες, που εμφανίζονται **μόνο αφού τα εγκρίνει ο διαχειριστής**.

## Λειτουργίες
**Για όλους**
- Χάρτης OpenStreetMap με pins: πράσινο ✓ = πλήρως προσβάσιμο, πορτοκαλί ! = μερικώς (σύμβολο και χρώμα, όχι μόνο χρώμα)
- Αναζήτηση (με ή χωρίς τόνους), φίλτρα κατηγορίας, επιπέδου και χαρακτηριστικών (ράμπα, ανελκυστήρας, WC, στάθμευση, οδηγός τυφλών, ηχητική σήμανση)
- Καρτέλα σημείου με περιγραφή, φωτογραφίες, «Οδηγίες διαδρομής», σύνδεσμος ανά σημείο (`/#p12`)
- Κουμπί «Η θέση μου», λειτουργεί σε κινητό
- Η ίδια η εφαρμογή είναι φιλική σε αναγνώστες οθόνης και πληκτρολόγιο (ARIA, skip link, μεγάλα κουμπιά, σκοτεινό θέμα)

**Συνδεδεμένοι χρήστες**
- Εγγραφή / σύνδεση με email και κωδικό
- «Πρόσθεσε σημείο»: επιλογή θέσης στον χάρτη (ή «Η θέση μου»), στοιχεία και έως 3 φωτογραφίες
- Προσθήκη φωτογραφίας σε υπάρχον σημείο
- «Οι υποβολές μου»: κατάσταση (σε αναμονή / εγκρίθηκε / απορρίφθηκε) και αιτία απόρριψης

**Διαχειριστής** (`/admin.html`)
- Ουρά εκκρεμών σημείων με μίνι χάρτη και φωτογραφίες· έγκριση, απόρριψη με αιτία, επεξεργασία πριν την έγκριση
- Επιλογή ποιες φωτογραφίες ενός σημείου εγκρίνονται
- Ουρά φωτογραφιών για ήδη εγκεκριμένα σημεία
- Λίστα εγκεκριμένων/απορριφθέντων με επεξεργασία και διαγραφή
- Οι υποβολές του διαχειριστή δημοσιεύονται απευθείας

**Ασφάλεια**: κωδικοί με scrypt, cookie συνεδρίας HttpOnly + SameSite=Strict, όριο προσπαθειών σύνδεσης,
έλεγχος ότι τα αρχεία είναι πραγματικά JPEG/PNG/WebP (έως 5 MB), οι μη εγκεκριμένες φωτογραφίες δεν
είναι δημόσια προσβάσιμες, Content-Security-Policy, δεκτά μόνο σημεία μέσα στα όρια του Δήμου Αρταίων.

## Εκκίνηση
Χρειάζεται **Node.js 22.13+** (χρησιμοποιεί την ενσωματωμένη SQLite, χωρίς εξωτερική βάση).

```bash
cd arta-access-map
npm install
ADMIN_EMAIL=admin@example.gr ADMIN_PASSWORD='ισχυρός-κωδικός' npm start
# → http://localhost:3000
```
Ο λογαριασμός του `ADMIN_EMAIL` δημιουργείται (ή γίνεται διαχειριστής) στην εκκίνηση.
Εναλλακτικά: `npm run create-admin -- email@example.gr κωδικός "Όνομα"`.

| Μεταβλητή | Περιγραφή |
|---|---|
| `PORT` | Θύρα (προεπιλογή 3000) |
| `DATA_DIR` | Φάκελος βάσης & φωτογραφιών (προεπιλογή `./data`) – κρατήστε backup |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Λογαριασμός διαχειριστή |
| `NODE_ENV=production` | Cookies μόνο μέσω HTTPS |
| `TRUST_PROXY=1` | Όταν τρέχει πίσω από reverse proxy (nginx, Render κ.λπ.) |

## Γέμισμα του χάρτη με δεδομένα
Κανένας χάρτης δεν έχει από μόνος του «όλα» τα προσβάσιμα σημεία – ο χάρτης χτίζεται με δύο τρόπους:

1. **OpenStreetMap**: `npm run import:osm` κατεβάζει ό,τι έχει ήδη καταγραφεί στο OSM για την περιοχή
   (`wheelchair=yes/limited`, WC ΑμεΑ, θέσεις στάθμευσης ΑμεΑ, ηχητικά φανάρια). Με `-- --pending` τα σημεία
   μπαίνουν πρώτα στην ουρά έγκρισης. Μπορεί να ξανατρέξει για ενημέρωση χωρίς διπλότυπα.
2. **Οι χρήστες** της εφαρμογής, με έγκριση από τον διαχειριστή.

`npm run seed:demo` προσθέτει 4 **δοκιμαστικά** σημεία (κατά προσέγγιση θέσεις, μη επαληθευμένα στοιχεία)
μόνο για επίδειξη – διαγράψτε τα πριν τη δημόσια λειτουργία.

## Tests
```bash
npm test
```
Ελέγχουν όλη τη ροή: εγγραφή → υποβολή με φωτογραφία → αόρατη μέχρι την έγκριση → έγκριση/απόρριψη,
δικαιώματα, έλεγχο αρχείων, όρια περιοχής και τη μετατροπή δεδομένων OSM.

## Δομή
```
server.js              εκκίνηση
src/app.js             API (Express): λογαριασμοί, σημεία, φωτογραφίες, διαχείριση
src/auth.js            κωδικοί, συνεδρίες, δικαιώματα
src/db.js              σχήμα SQLite
src/constants.js       κατηγορίες, χαρακτηριστικά, όρια Άρτας
public/                χάρτης (index.html) και διαχείριση (admin.html)
scripts/               create-admin, import-osm, seed-demo
```

## Δημοσίευση στο Cloudflare (χωρίς server)
Υπάρχει έκδοση για **Cloudflare Pages + D1** (δωρεάν πρόγραμμα): `npm run build:cloudflare` φτιάχνει το
`arta-cloudflare.zip` και οι οδηγίες είναι στο [ΟΔΗΓΙΕΣ-CLOUDFLARE.md](ΟΔΗΓΙΕΣ-CLOUDFLARE.md).
Ο κώδικας του server γι' αυτή την έκδοση είναι στο `cloudflare/_worker.js` (ίδιο API με το `src/app.js`).
Οι φωτογραφίες σμικρύνονται στον browser (έως 1600px) και αποθηκεύονται στη D1.

## Δημοσίευση σε δικό σας server
Τρέχει σε οποιονδήποτε server/VPS με Node.js. Χρειάζεται **μόνιμο δίσκο** για τον `DATA_DIR`
(η βάση και οι φωτογραφίες ζουν εκεί) και HTTPS μπροστά (π.χ. nginx + Let's Encrypt).
Τα πλακίδια χάρτη έρχονται από το tile.openstreetmap.org· για μεγάλη κίνηση δείτε την
[πολιτική χρήσης](https://operations.osmfoundation.org/policies/tiles/) και σκεφτείτε άλλον πάροχο.
