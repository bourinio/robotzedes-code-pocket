# Ανέβασμα στο Cloudflare – βήμα βήμα

Χρειάζεσαι μόνο δωρεάν λογαριασμό στο Cloudflare και το αρχείο **arta-cloudflare.zip**.
(Αν δεν το έχεις: `npm install && npm run build:cloudflare` μέσα στον φάκελο `arta-access-map`.)

> Τα ονόματα των μενού στο Cloudflare αλλάζουν κάπου κάπου. Αν κάτι δεν το βρίσκεις ακριβώς έτσι, ψάξε κάτι παρόμοιο.

## 1. Ανέβασε την εφαρμογή
1. Μπες στο https://dash.cloudflare.com
2. Αριστερά: **Workers & Pages** → **Create** → καρτέλα **Pages** → **Upload assets** (ή «Use direct upload»).
3. Δώσε όνομα, π.χ. `prosvasimi-arta` → **Create project**.
4. Σύρε μέσα το **arta-cloudflare.zip** → **Deploy site**.

## 2. Φτιάξε τη βάση δεδομένων
1. Αριστερά: **Storage & Databases** → **D1 SQL Database** → **Create**.
2. Όνομα: `arta-db` → **Create**. (Οι πίνακες φτιάχνονται μόνοι τους.)

## 3. Σύνδεσε τη βάση με την εφαρμογή
1. Γύρνα στο **Workers & Pages** → πάτησε το `prosvasimi-arta` → **Settings**.
2. **Bindings** → **Add** → **D1 database**.
3. Variable name: **`DB`** (ακριβώς έτσι, κεφαλαία) → Database: `arta-db` → **Save**.

## 4. Δήλωσε ποιος είναι ο διαχειριστής
1. Στο ίδιο **Settings** → **Variables and Secrets** → **Add**.
2. Variable name: **`ADMIN_EMAIL`**, Value: το email σου → **Save**.

## 5. Ξανανέβασε το zip (σημαντικό)
Οι ρυθμίσεις των βημάτων 3–4 ισχύουν μόνο σε νέο ανέβασμα:
**Deployments** → **Create deployment** (ή «Upload assets») → σύρε ξανά το ίδιο zip → **Deploy**.

## 6. Έτοιμο!
1. Άνοιξε `https://prosvasimi-arta.pages.dev` (το όνομα που διάλεξες στο βήμα 1).
2. **Σύνδεση** → **Νέος λογαριασμός** με το email του βήματος 4 → είσαι διαχειριστής
   (εμφανίζεται το κουμπί **Διαχείριση**).
3. Προαιρετικά: **Διαχείριση** → κάτω κάτω **Εισαγωγή σημείων από το OpenStreetMap**.

## Αν κάτι δεν πάει καλά
- **«Δεν έχει συνδεθεί η βάση D1»** → έλεγξε το βήμα 3 (όνομα `DB`) και κάνε ξανά το βήμα 5.
- **Δεν βλέπω «Διαχείριση»** → το email του λογαριασμού πρέπει να είναι ίδιο με το `ADMIN_EMAIL`
  και να έχει γίνει το βήμα 5. Κάνε έξοδο και ξανά σύνδεση.
- Για αλλαγές στην εφαρμογή στο μέλλον: ανεβάζεις νέο zip στο **Create deployment**. Τα δεδομένα
  (σημεία, χρήστες, φωτογραφίες) μένουν στη βάση και δεν χάνονται.

Το δωρεάν πρόγραμμα του Cloudflare αρκεί για μια πόλη σαν την Άρτα (5 GB βάση, 100.000 αιτήματα την ημέρα).
