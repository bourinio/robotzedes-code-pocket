# RoboAtlas

Ανεξάρτητη εφαρμογή για όλο τον κόσμο της εκπαιδευτικής ρομποτικής, στα ελληνικά και στα αγγλικά.
Λειτουργεί offline, ως web εφαρμογή (PWA) σε κάθε συσκευή ή ως APK για Android.

## Για ποιους είναι
| Ρόλος | Τι βλέπει |
|---|---|
| 👥 Ομάδα / Προπονητής | Πολλές ομάδες, σε ποιους διαγωνισμούς μπορεί να πάει η καθεμία (✓ / ! / ✕ με αιτιολόγηση), τι εξοπλισμό να αγοράσει, πλάνο προετοιμασίας, κάρτα ομάδας για χορηγούς |
| 🎒 Μαθητής / Γονέας | Αναζήτηση διαγωνισμών με βάση ηλικία και χώρα |
| 🏪 Προμηθευτής | Ζήτηση ανά πλατφόρμα (πόσοι διαγωνισμοί τη δέχονται ή την απαιτούν), καταχώριση επιχείρησης |
| 🏆 Διοργανωτής | Υποβολή διαγωνισμού με κατηγορίες, ηλικίες, μέλη και επιτρεπόμενο εξοπλισμό |

## Ενότητες
- **Διαγωνισμοί**: 16 διαγωνισμοί σε όλο τον κόσμο (WRO, FIRST LEGO League, FTC, FRC, FIRST Global, VEX IQ/V5, RoboCup Junior, RoboCup, Robotex, MakeX, Botball, Eurobot, European Rover Challenge, ΕΕΛΛΑΚ…). Για τον καθένα: η επόμενη φάση, το χρονοδιάγραμμα της σεζόν, οι εγγραφές, οι κατηγορίες και οι κανόνες. Φίλτρα: χώρα, εγγραφές τώρα, για αρχάριους, ηλικία, εξοπλισμός.
- **Ομάδες**: προφίλ (χώρα, μαθητές, ηλικίες, εμπειρία, εξοπλισμός, προϋπολογισμός, ταξίδι, προπονητής, σχολείο, τι αναζητά η ομάδα).
- **Εξοπλισμός & προμηθευτές**: 16 πλατφόρμες με τιμές, ηλικίες, σε ποιους διαγωνισμούς χρησιμοποιείται η καθεμία και ποιοι από τους 23 προμηθευτές τη διαθέτουν (πρώτα όσοι είναι στην περιοχή σου).
- **Μενού**: γλώσσα, χώρα, θέμα, εξαγωγή/εισαγωγή ομάδων, συνεισφορά.

## Πώς αποφασίζει
Ελέγχει κάθε κατηγορία: χώρα, ηλικίες όλων των μαθητών, μέλη (με πρόταση διαχωρισμού σε ομάδες), εξοπλισμό (αν λείπει, προσθέτει το κόστος αγοράς), προπονητή, σχολείο, εθνική φάση ή ταξίδι στο εξωτερικό, προϋπολογισμό (μαζί με εκτίμηση ταξιδιού), εμπειρία και χρόνο προετοιμασίας.
- **✕** αμετάβλητο εμπόδιο · **!** λύνεται (αγορά, χορηγός, εκπαίδευση, έλεγχος εθνικής φάσης) · **✓** μπορεί να συμμετάσχει
- Οι πληροφορίες (i) δεν αλλάζουν την απόφαση (π.χ. «στόχος η επόμενη σεζόν»).

## Δομή
```
roboatlas/
  web/                  η εφαρμογή (HTML/CSS/JS χωρίς build)
    data/competitions.js  διαγωνισμοί · data/equipment.js  εξοπλισμός · data/suppliers.js  προμηθευτές
    js/engine.js          ημερομηνίες & καταλληλότητα (χωρίς DOM, με tests)
    js/i18n.js            κείμενα EL/EN, χώρες, RA_CONFIG (email/GitHub για καταχωρίσεις)
    js/app.js             σελίδες & πλοήγηση
    sw.js, manifest.webmanifest   offline / εγκατάσταση ως εφαρμογή
  android/              wrapper Android (WebView) που φορτώνει το web/
  tests/engine.test.js  node --test roboatlas/tests/engine.test.js
```

## Εκτέλεση
- **Browser**: άνοιξε το `web/index.html`. Για offline/εγκατάσταση (PWA) σέρβιρέ το μέσω http(s), π.χ. `npx serve roboatlas/web` ή GitHub Pages / Netlify.
- **APK**: Actions → **RoboAtlas** → artifact **RoboAtlas-APK**.

## Ενημέρωση δεδομένων
Οι ημερομηνίες είναι η *συνήθης* περίοδος κάθε φάσης και οι κανόνες ενδεικτικοί. Κάθε σεζόν ενημέρωσε τα `data/*.js` από τους επίσημους κανονισμούς.
Αν προσθέσεις χώρα σε `natIn` κάποιου διαγωνισμού, οι ομάδες της βλέπουν «υπάρχει εθνική φάση». Για να φτάνουν οι καταχωρίσεις προμηθευτών και διοργανωτών, συμπλήρωσε το `RA_CONFIG` στο `js/i18n.js`.
